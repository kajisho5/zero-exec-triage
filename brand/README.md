# zero-exec triage brand

The app icon and logo follow the brand format of [fresnel](https://github.com/kajisho5/fresnel). The Liquid Glass `.icon` bundle (Apple Icon Composer format) is generated by the fresnel CLI ([fresnel-icon](https://www.npmjs.com/package/fresnel-icon), MIT) from `src/spec.json` and two layer SVGs.

The three products ZES / ZET / GER share the same composition and differ only in shape and accent color. Back = a bar in 3 tiers (sorting by severity); front = a dot (one verdict).

## Regenerating

```bash
cd brand
python3 src/layers.py zet                  # layer SVGs (requires shapely; only when the shape changes)
python3 src/wordmark.py "zero-exec triage"   # wordmark (requires fonttools and Inter Display SemiBold; only when the text changes)
npm ci && npm run build                     # writes out the .icon and all the assets below
```

`npm ci` does not run install scripts, because `.npmrc` sets `ignore-scripts=true`. fresnel-icon 0.2.2 does not export its renderer as a public API, so `build.mjs` creates a module inside `node_modules` from the bundled `dist/cli.js` with the CLI start-up part removed, and loads that. When you upgrade fresnel-icon, check the output visually.

The Japanese text in the social images is drawn with a system font, so the pixels vary by environment (the icon, logo and favicon are confirmed to produce the same output from the same input).

## Guidelines (same as fresnel)

- The composition is a background + 2 glass groups. Do not bake highlights or shadows into the layers (add them through the .icon settings)
- Where the platform applies a mask (apple-touch-icon, maskable), use the no-mask version
- Below 24 px, use the icon alone without the wordmark. Minimum 16 px
- The wordmark is `#F5F5F7` on dark backgrounds and `#1D1D1F` on light backgrounds. Write the name in lowercase
- The wordmark typeface is Inter Display SemiBold (SIL OFL 1.1) converted to outlines. Do not use Apple's trademarks
